ChatDB (Text2SQL Multi-Agent Framework)

ChatDB allows querying a large database (the Chinook database) using natural language, by dividing the task among four agents: a Planner that breaks the user query into simpler sub-tasks, a Selector that picks the appropriate tables, a Generator that constructs the complex SQL query, and an Executor that runs the query and returns the results to the user.
